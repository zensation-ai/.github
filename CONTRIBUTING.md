# Contributing to ZenSation projects

Thank you for taking the time. This guide applies to every repository of the `zensation-ai` organization that has no
`CONTRIBUTING.md` of its own; [`zenbrain`](https://github.com/zensation-ai/zenbrain/blob/main/CONTRIBUTING.md) has a detailed one.

## What helps most

- **Replications and counter-results.** If you re-run one of our measurements and get a different result, open an issue with
  your setup and numbers. A result that does not hold is worth more to us than a confirmation.
- **Bug reports** with a minimal reproduction, the version you used and what you expected.
- **Small, focused pull requests.** One change per pull request, with tests where the repository has them.

## How to contribute

1. Look for an existing issue, or open one first for anything larger than a typo, so we can agree on the approach.
2. Fork the repository and create a branch from the default branch.
3. Follow the setup and test commands in the repository's README.
4. Open a pull request that says what changed and why, and link the issue.

Issues and pull requests are answered.

## Code of Conduct

By participating you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Security

Please report vulnerabilities privately, as described in our [Security Policy](SECURITY.md), not in a public issue.
