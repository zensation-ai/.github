# ZenSation AI

**Neuroscience-inspired AI tools. Open source.**

We build memory systems that help AI agents remember like humans do — with spaced repetition, emotional tagging, Hebbian learning, and exponential forgetting curves.

## Our Projects

### 🧠 [ZenBrain](https://github.com/zensation-ai/zenbrain)
The neuroscience-inspired memory system for AI agents. 7-layer architecture with FSRS, Hebbian dynamics, and emotional memory.

```bash
npm install @zensation/algorithms
```

### 🤖 [ZenAI](https://github.com/zensation-ai/zenai)
The self-hosted AI OS powered by ZenBrain — multi-agent system, knowledge graph, and persistent memory. Ships the [`@zensation/cli`](https://www.npmjs.com/package/@zensation/cli) terminal agent.

- **Corpus:** **11 open records** on Zenodo — nine preprints and two software / reproduction packages, all CC BY 4.0, each with its own version and concept DOI. Complete list with DOIs: [zensation.ai/en/publikationen](https://zensation.ai/en/publikationen)
- **Author ID:** [ORCID 0009-0001-1793-012X](https://orcid.org/0009-0001-1793-012X)
- **Prior art:** defensive publications on [Technical Disclosure Commons](https://www.tdcommons.org)

Benchmarks are reported with the protocol, the effect sizes and the cases where the system loses — the ZenBrain paper concedes retrieval-proper metrics to a competing system and an aggregate-F1 metric to lexical search. Reproduction material ships with the records.
